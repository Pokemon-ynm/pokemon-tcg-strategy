# Dawn of the Dipplin: Eight Small Policies, One Big Festival

Supporting material for our Strategy write-up in the **Pokémon TCG AI Battle Challenge (2026)**.

> 日本語: [README.ja.md](README.ja.md)

- Write-up on Kaggle: [Dawn of the Dipplin: Eight Small Policies, One Big Festival](https://www.kaggle.com/competitions/pokemon-tcg-ai-battle-challenge-strategy/writeups/new-writeup-1788440804579)
- Team **perrodawn** — perrodawn, tora, RB25det, Shinzo Takayama
- Simulation track: **26th of 6,807 teams**, final score **1123.7**

## Summary

We built an agent dedicated to the Festival Lead deck (Dipplin + Thwackey) by combining imitation
learning (IL) on demonstrations generated by a rule-based agent, league-style reinforcement learning
(RL), matchup-specialized RL, policy switching based on public information, and a lethal search that
looks for a guaranteed winning line.

As an all-student team with limited compute, we used **eight policies of about 0.83M parameters
each** — one generalist and seven matchup specialists — that share one 60-card deck, rather than
training a single large model.

## Results at a glance

| | |
|---|---|
| Simulation track | **26th / 6,807 teams**, final score **1123.7** |
| Final evaluation period | **1,330 games, 781–549 (58.7%)** |
| Generalist alone → eight models used selectively (12 matchups × 1,000 games) | **48.9% → 63.9%** |
| RL with the rule-based lethal detector | reached the control's final win rate (53.6%) after about **207 iterations** — **31% fewer iterations**, about **29% less wall-clock time**, at **+3.4%** time per iteration |
| Rabsca feedback against Dragapult ex | win rate **20.0% → 55.6%**; Rabsca in play **8.5% → 62.8%** |

## Not included

This repository holds the evidence for the write-up. It does not include the agent's source code,
trained weights or training logs, or the competition's simulator library (`cg/`), which we do not
redistribute. No card images or game assets are redistributed; card names and effect text are quoted
from the competition simulator's card database only to explain the deck.
